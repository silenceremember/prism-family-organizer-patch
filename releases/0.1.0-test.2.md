# 0.1.0-test.2

Disposable UI/restart prerelease of **Prism Family Organizer Patch**.

- Reworked the Settings page into a themed Organizer card with action/link icons.
- Added direct GitHub and Releases links.
- Added exact `downloaded / total` byte progress and percentage.
- Added explicit verification and automatic-restart states.

Includes PineconeMC 11.0.3, Prism Launcher 11.0.3, Freesm Launcher 2.2.0, and the maintenance helper for Windows x64.

This remains a test-only prerelease and will be deleted/repacked after acceptance.
