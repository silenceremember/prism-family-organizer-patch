# 0.1.0-test.4

Disposable unified-installer prerelease of **Prism Family Organizer Patch**.

- Replaced the separately deployed maintenance helper with one Organizer Patch Installer.
- The installer owns guarded `install`, `update`, and `remove` transactions.
- Every family launcher embeds its exact installer executable as a Qt resource and extracts it only when needed.
- Update and Remove now launch the embedded installer; no helper file is required under `.organizer-patch`.
- A fresh install preserves and verifies the pristine launcher before replacement.
- Existing SHA-256 verification, same-directory rollback, atomic state, lock wait, cleanup, and restart behavior remain intact.

Includes PineconeMC 11.0.3, Prism Launcher 11.0.3, Freesm Launcher 2.2.0, and the shared installer engine for Windows x64.

This remains a test-only prerelease and will be deleted/repacked after acceptance.
