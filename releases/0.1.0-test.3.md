# 0.1.0-test.3

Disposable branding prerelease of **Prism Family Organizer Patch**.

- Added the supplied Organizer logo to the global Settings navigation.
- Added the wide Organizer mark to the maintenance card.
- The card automatically switches between light and dark logo variants when the launcher theme changes.
- Embedded all SVG assets in each family executable; no loose logo files are required after installation.

Includes PineconeMC 11.0.3, Prism Launcher 11.0.3, Freesm Launcher 2.2.0, and the maintenance helper for Windows x64.

This remains a test-only prerelease and will be deleted/repacked after acceptance.
