# 0.1.0-test.1

Disposable prerelease of **Prism Family Organizer Patch**.

Included maintenance payloads:

- PineconeMC 11.0.3 (Windows x64)
- Prism Launcher 11.0.3 (Windows x64)
- Freesm Launcher 2.2.0 (Windows x64)
- Organizer Patch maintenance helper (Windows x64)

The new global settings page exposes `Check`, `Update`/`Latest`, the installed patch version, and `Remove`. Downloads are selected by launcher family and SHA-256 verified. Update failures roll back the executable; removal restores the pristine executable captured during installation.

This release is intentionally marked as a prerelease and will be deleted/repacked after the update path is accepted.
