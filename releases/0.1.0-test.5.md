# 0.1.0-test.5

Disposable graphical-manager prerelease of **Prism Family Organizer Patch**.

- Settings now keeps two stable actions: **Check** and **Manage**.
- **Manage** downloads the dedicated manager asset from GitHub Releases, verifies GitHub's SHA-256 digest, and launches it from a temporary directory.
- The separate true-dark manager displays installed/latest versions, exact byte progress, Update, Remove, and Close.
- Update and Remove retain the guarded same-directory rollback transaction and restart the launcher automatically.
- Closing the manager without making a change also returns to the launcher.
- Organizer SVGs are rendered directly through QtSvg, and action buttons use guaranteed standard-style icons instead of optional theme icon names.
- Family launchers no longer embed the manager executable.

Includes PineconeMC 11.0.3, Prism Launcher 11.0.3, Freesm Launcher 2.2.0, and the shared graphical manager for Windows x64.

This remains a test-only prerelease and will be deleted/repacked after acceptance.
