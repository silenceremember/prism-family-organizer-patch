# 0.1.0-test.6

Disposable Flutter-manager prerelease of **Prism Family Organizer Patch**.

- Replaces the provisional Qt Widgets manager with a separately downloaded Flutter Windows application.
- Restores valid Organizer SVG sources and packages both visible branding assets plus the native Windows application icon.
- Adds contextual **Install**, **Reinstall**, **Update**, and **Remove** actions.
- Shows the selected launcher, detected family, installed/latest versions, status, exact downloaded bytes, and total size.
- Keeps the family launcher Settings page limited to **Check** and **Manage**.
- **Manage** SHA-verifies the manager ZIP, extracts it with the launcher's archive layer, starts it, and closes the launcher.
- The Flutter bundle owns guarded install/update/removal directly; it has no Qt runtime or helper-executable dependency.
- Install/reinstall/remove preserve the pristine launcher, use a same-directory rollback, update state atomically, and restart automatically.

Includes PineconeMC 11.0.3, Prism Launcher 11.0.3, Freesm Launcher 2.2.0, and the shared Flutter manager for Windows x64.

This remains a test-only prerelease and will be deleted/repacked after acceptance.
